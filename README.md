Flappy Bird – C++ SFML Semester Project

1. Game Description

Flappy Bird is a 2D arcade-style game developed using C++ and the SFML (Simple and Fast Multimedia Library) framework.

In this game, the player controls a bird that moves through a series of pipes. The bird is affected by gravity, and the player must press the Space key to make it jump and avoid obstacles.

The objective is to pass through as many pipes as possible without colliding with them. Each successfully passed pipe increases the player's score. The game ends when the bird hits a pipe, the ground, or the top boundary of the screen.

 2. Game Features

- Start Menu: Displays the game title and Play screen.
- Bird Design: A bird created using SFML shapes, including its body, wing, eye, pupil, and beak.
- Gravity and Jumping:The bird falls due to gravity and jumps when the player presses Space.
- Moving Pipes: Green pipes move from right to left across the screen.
- Random Pipe Gaps: Pipe gaps change position when new pipes appear.
- Collision Detection: Detects collisions between the bird and pipes, ground, or screen boundary.
- Score System: Increases the score when the bird successfully passes a pipe.
- Pause and Resume: Allows the player to pause and resume the game.
- Game Over Screen: Displays the final score when the game ends.
- Restart Option: Allows the player to restart the game.
- Background Graphics: Includes clouds, trees, hills, and a sun.

8. How to Play

1. Run the game.
2. The Start Menu will appear.
3. Press Space to start playing.
4. Press Space whenever you want the bird to jump.
5. Avoid hitting the pipes, ground, and top boundary.
6. Pass through pipes to increase your score.
7. Press P to pause or resume.
8. When the Game Over screen appears, press R to restart.
9. Press X to exit the game.
